# Ad Creative Canvas — Design Ideas

## Chosen Approach: Dark Intelligence Board

**Design Movement:** Editorial Intelligence / War Room Aesthetic
**Core Principles:**
- Dark, high-contrast surface that makes ad images pop like physical prints pinned to a board
- Monospace + grotesque type pairing for a data-intelligence feel
- Tight information density with clear visual hierarchy — no wasted space
- Color-coded angle taxonomy (each creative angle gets a distinct accent color)

**Color Philosophy:**
- Background: near-black (#0D0D0F) — makes images feel like they're glowing
- Surface cards: dark charcoal (#161618) with subtle border
- Accent colors per angle: Electric blue (Before/After), Amber (Offer/Discount), Emerald (Social Proof), Rose (Pain/FOMO), Violet (Process), Slate (Features)
- Text: off-white (#F0EEE9) for primary, muted grey for secondary

**Layout Paradigm:**
- Left sidebar: angle filter navigation with color-coded pills
- Main area: masonry-style card grid, images at natural aspect ratios
- Top bar: search + filter controls
- Cards: image dominant, with a bottom annotation strip showing angle tag, niche, and source link

**Signature Elements:**
- Color-coded angle badge on each card (top-left corner)
- Hover state reveals annotation overlay with breakdown: Hook type, Trust element, CTA type, Copy formula
- "Replication Blueprint" drawer that slides in on card click

**Interaction Philosophy:**
- Click card → full-screen lightbox with detailed breakdown panel
- Filter by angle → smooth grid reflow
- Hover → annotation overlay fades in

**Animation:**
- Cards entrance: staggered fade-up on load
- Filter transitions: layout shift with spring physics
- Lightbox: scale-up from card position

**Typography System:**
- Display: Space Grotesk Bold — for angle labels and headlines
- Body: Inter 400/500 — for annotations and descriptions
- Mono: JetBrains Mono — for metadata tags and source URLs
